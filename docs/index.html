Network Metrics

Degree Centrality

CD(v) = deg(v) / (n-1)

Number of direct connections. High degree = many cooperation partners.

Betweenness Centrality

CB(v) = Σ (σst(v) / σst)

Bridge position in network. High betweenness = connects different clusters.

Closeness Centrality

CC(v) = (n-1) / Σ d(v,u)

Average distance to all other nodes. High closeness = fast information spread.

Eigenvector Centrality

CE(v) = (1/λ) Σ Avu CE(u)

Connections to important nodes. High eigenvector = connected to central players.

Data Quality & Limitations

⚠️ Synthetic Data Notice

This visualization uses synthetic/placeholder data generated for development purposes. Results do not reflect real-world patent cooperation patterns.

🔴 Network Density: 95.9%

Almost all nodes are connected (unrealistic). Real patent networks typically have 5-20% density.

Impact: Betweenness Centrality values very low and similar across countries.

🔴 Modularity: 0.010

Community detection failed (statistically insignificant). No meaningful clusters found.

Impact: Region-based coloring used instead of community colors.

ℹ️ Temporal Snapshots: 9 years

Annual sampling (2010-2018, all years). Complete yearly coverage available.

Impact: Year-by-year dynamics visible via Time Slider.
